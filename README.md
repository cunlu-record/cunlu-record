## 怎么验证

下载后，在文件所在的文件夹里运行：

```
Get-FileHash -Algorithm SHA256 文件名
```

或者 macOS / Linux：

```
shasum -a 256 文件名
```

**和 `HASHES.txt` 里那一串对一下。**

对不上怎么办：

1. 回这里重新下载一次
2. 看 `cunlu-original.md` 里 `000-前言` 那五条还在不在
3. 还不对 → 这份不是原件
